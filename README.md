# ASKREADY

ASKREADY helps homebuyers generate clear questions to ask a lender or realtor before making decisions.

## What it does

- Lets a user choose lender or realtor questions
- Tailors questions based on where they are in the buying process
- Adds questions around cost, timeline, risk, or confidence
- Includes a custom concern field
- Copies the final list so it can be saved or shared

## How to test locally

Open `index.html` in a browser, or run a local web server from this folder.
